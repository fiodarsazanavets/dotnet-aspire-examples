# .NET Aspire Examples

Example projects of .NET Aspire.

**IMPORTANT!** this repository only covers examples for .NET Aspire 9, which has been superceeded by the evergreen Aspire 13. For the latest examples, you can visit this repository:

[https://github.com/fiodarsazanavets/aspire-13-examples](https://github.com/fiodarsazanavets/aspire-13-examples)

The majority of these samples are used by the book [.NET Aspire Made Easy](https://www.manning.com/books/dotnet-aspire-made-easy/)
